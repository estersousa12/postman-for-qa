# 🧪 Postman for QA

Projeto desenvolvido para prática e demonstração de testes de APIs REST utilizando Postman e APIs públicas.

## 📌 Conteúdo

- Collections organizadas por API
- Environments para configuração de ambientes
- Requisições GET, POST, PUT e DELETE
- Validação de Status Code
- Validação de Response Body
- Validação de Schema
- Scripts de testes no Postman
- Documentação dos cenários e requisições

## 🎯 Objetivo

Demonstrar conhecimentos em testes de APIs REST, organização de collections, execução de requisições e validação de respostas utilizando Postman.

---

**Tecnologias:** Postman • APIs REST • JSON • JavaScript
