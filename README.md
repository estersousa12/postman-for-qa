# 🧪 Postman for QA

Projeto desenvolvido com foco em **testes de APIs REST utilizando Postman**, demonstrando organização de Collections, documentação técnica, ambientes reutilizáveis e scripts automatizados de validação.

O objetivo deste repositório é apresentar boas práticas aplicadas por um **QA Analyst** durante a criação, execução e documentação de testes de APIs.

Todos os exemplos utilizam **APIs públicas** e **dados fictícios**, sendo destinados exclusivamente para fins de estudo e composição de portfólio profissional.

# 📌 Sobre o projeto

Este projeto reúne exemplos práticos de documentação e validação de APIs REST utilizando o **Postman**.

Seu objetivo é demonstrar uma estrutura organizada para testes de APIs, incluindo:

- Collections
- Environments
- Documentação técnica
- Scripts de validação
- Organização do projeto
- Boas práticas de QA

Todas as requisições utilizam APIs públicas, sem exposição de informações sensíveis.

# 🚀 Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/estersousa12/postman-for-qa.git
```

### 2. Abra o Postman

Importe a Collection disponível na pasta:

```
collections/
```

### 3. Configure o Environment

Importe ou crie um ambiente utilizando as variáveis descritas em:

```
environments/
```

### 4. Execute as requisições

Cada requisição possui:

- Headers
- Variáveis
- Scripts de teste
- Validações
- Exemplos de resposta
