# 📚 Documentação do Projeto

Esta pasta reúne a documentação técnica utilizada durante o desenvolvimento dos testes de API REST deste projeto.

O objetivo é centralizar informações sobre autenticação, estrutura das requisições, boas práticas e conceitos utilizados na Collection do Postman.

---

# 📖 Conteúdo

Esta documentação aborda:

- Fluxo de autenticação
- Headers HTTP
- Query Parameters
- Path Parameters
- Request Body
- Response Body
- Status Codes HTTP
- Estrutura das requisições
- Scripts de validação do Postman
- Boas práticas para testes de API

# 🧪 Padrão utilizado nas documentações

Cada documentação deste projeto procura seguir uma estrutura padronizada contendo:

- Objetivo
- Endpoint
- Método HTTP
- Headers
- Path Parameters
- Query Parameters
- Request Body
- Exemplo de resposta
- Status Code esperado
- Scripts de validação
- Observações

# ✅ Boas práticas adotadas

- Utilização de variáveis de ambiente (`{{base_url}}`)
- Organização das requisições por método HTTP
- Documentação padronizada
- Scripts automatizados utilizando Postman
- Utilização de APIs públicas para estudo
- Nenhum dado sensível armazenado no repositório
